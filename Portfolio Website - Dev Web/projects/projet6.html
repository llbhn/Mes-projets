Création d'un site web de présentation de l'Argentine

2025 HTML / CSS / JavaScript

Objectif du Projet

Développer un site web touristique complet sur l'Argentine. Ce projet présente les merveilles naturelles, culturelles et historiques de l'Argentine à travers une interface web interactive et responsive.

  • Créer une interface web attractive et intuitive
  • Présenter l'Argentine sous différentes thématiques (géographie, culture, personnages, art)
  • Implémenter une navigation fluide et logique
  • Intégrer des médias (images, cartes, vidéos)
  • Assurer une compatibilité responsive (mobile/desktop)
  • Appliquer les principes d'UX/UI modernes
1

Architecture du Site

Le site est organisé autour de 4 sections principales accessibles via un menu de navigation persistent :

  • Accueil (index.html) : Page principale présentant l'Argentine avec géographie et carte interactive
  • Personnages (persoNav.html) : Figures importantes de l'histoire argentine (Maradona, Eva Perón, etc.)
  • Art (ArtNav.html) : Culture artistique et musicale (street art, tango etc.)
  • Lieux (lieuxNav.html) : Destinations touristiques incontournables (Buenos Aires, Patagonie, etc.)

Pages Spécialisées

Chaque section thématique dispose de pages détaillées :

  • Pages Personnages : Biographies illustrées avec contexte historique
  • Pages Art : Galeries d'images et descriptions des mouvements artistiques
  • Pages Lieux : Descriptions détaillées avec images et cartes d'accès
  • Intégration multimédia : Cartes Google Maps, Slider d'images, images optimisées, textes enrichis

Design Responsif

Le design respecte les standards du web moderne :

  • Palette de couleurs : Couleurs argentines (bleu et blanc) avec accents verts
  • Typography : Hiérarchie claire avec différents niveaux de titres
  • Layout Grid : Système de grille flexible pour adaptabilité
  • Images optimisées : Formats modernes et chargement efficace
  • Responsive design : Adaptation mobile, tablette, desktop
