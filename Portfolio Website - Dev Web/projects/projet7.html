Mon Portfolio Web

2025
HTML / CSS / JavaScript

Objectif du Projet

Développer un portfolio web professionnel présentant l'ensemble de mes projets académiques et compétences en développement web. Ce projet démontre ma capacité à concevoir et mettre en place une plateforme complète de A à Z.

  • Créer une interface moderne et responsive
  • Présenter 6+ projets académiques
  • Implémenter la navigation et l'interactivité
  • Optimiser la performance et l'accessibilité
  • Assurer une compatibilité cross-browser
  • Appliquer une charte graphique cohérente
1

Conception et Architecture

La première étape a consisté à définir la structure globale du portfolio :

  • Page d'accueil (index.html) : Présentation personnelle et navigation vers les projets
  • Pages projets (projet1-7.html) : Détail de chaque projet avec descriptions et captures
  • Feuille de styles CSS : Système de variables pour cohérence visuelle
  • Scripts JavaScript : Navigation responsive et interactions

J'ai créé une architecture modulaire permettant l'ajout facile de nouveaux projets sans modification du code existant.

2

Développement Frontend - HTML et CSS3

Création d'une structure sémantique HTML5 avec CSS3 moderne :

  • Sémantique HTML : Utilisation de tags appropriés (header, nav, article, section, footer)
  • CSS Flexbox et Grid : Layouts responsifs et adaptatifs
  • Variables CSS : Gestion centralisée des couleurs et espacements
  • Media Queries : Adaptation pour mobile, tablette, desktop
  • Gradients et animations : Effets visuels modernes et fluides

Le portfolio utilise une palette de couleurs cohérente avec transitions douces pour une expérience utilisateur optimale.

3

Intégration des Projets Académiques

Chaque projet a été intégré avec son propre contenu détaillé :

  • Projet 1 : Simulation Wazuh - Détection de brute force
  • Projet 2 : Cisco Packet Tracer - Simulation réseau
  • Projet 3 : HTB - Capture The Flag
  • Projet 4 : Sokoban Game - WASM et C
  • Projet 5 : Quiz Game - HTML/CSS/JavaScript
  • Projet 6 : Création d'un site web de présentation de l'Argentine - Site web complet
  • Projet 7 : Portfolio - Ce projet lui-même

Chaque page projet inclut captures d'écran, descriptions détaillées et technologies utilisées.

4

Fonctionnalités et Optimisations

Le portfolio incorpore plusieurs fonctionnalités avancées :

  • Navigation responsive : Menu hamburger sur mobile
  • Système de recherche : Filtrage des projets
  • Animations CSS : Effets de survol et transitions
  • Performance : Images optimisées, CSS/JS minifiés
  • Accessibilité : Contraste WCAG AAA, alt text, navigation au clavier
  • SEO : Meta tags, structure heading correcte

Technologies utilisées :

  • HTML5 - Structure sémantique
  • CSS3 - Flexbox, Grid, animations
  • JavaScript Vanilla - Interactivité et DOM manipulation
  • Google Fonts - Typographie moderne
  • Responsive Design - Mobile-first approach
