⚙️ Contrôles

Mouvements: 0

Clavier

Z Haut
S Bas
Q Gauche
D Droite

📖 Règles du Jeu

  • Objectif : Poussez toutes les caisses ($) sur les cibles (.) en utilisant les flèches directionnelles.
  • Joueur : Vous êtes le caractère (@). Déplacez-vous avec Z/Q/S/D.
  • Caisses : Poussez-les une par une sur les cibles. Une caisse sur une cible apparaît comme (*)
  • Murs : Les caractères # sont des murs infranchissables.
  • Victoire : Le niveau est complété quand toutes les caisses sont sur les cibles.
  • Astuce : Essayez de minimiser le nombre de mouvements!

🎯 Symboles

@ Vous
+ Vous sur cible
$ Caisse
* Caisse placée
. Cible
# Mur
